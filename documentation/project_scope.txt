Project Goals
- Receive data from satellite and convert data to image
    - Should take no more than 10 minutes to display image
    - Image should be (relatively) real time
    - Image will be displayed on external computer display via USB (potentially its own standalone unit)
    - Process does not have to be continuous
    - The accuracy of the image should be verified with an external resource
- The user will push a button to initiate the process. This process will end by an image being displayed.
- The device should be able to be carried by a single person
